# Learning Java - Introduction To Programming In Java: An Interdisciplinary Approach by Robert Sedgewick and Kevin Wayne (2nd Ed)

### ABOUT
A basic Java relearning course repository containing notes and solutions to Sedgewick and Wayne's An Introduction To Programming In Java (2nd Edition). This repository is fully intended to be used as an additional introductory exercise hub in Java, honing the theoretical and practical usage of the programming language.

*Note: No solution in this book is assisted or edited by AI to facilitate critical thinking and enable confidence in answering future coding questions and problems.*
